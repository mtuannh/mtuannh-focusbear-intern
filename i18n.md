### What challenges did you face while setting up i18next?

The main challenge was understanding how i18next connects the translation files with the React components. I needed to configure the languages and make sure the translation keys matched the keys used in the component.

### Why is it important to use a library like i18next instead of manually handling translations?

A library like i18next makes translations easier to manage when an application supports multiple languages. Instead of writing separate conditions for each language, translations can be stored in separate files and accessed using translation keys.

This also makes it easier to add more languages later without changing the main component logic.

### How would you handle dynamic content (e.g., user-generated text) in a multilingual app?

I would keep user-generated content separate from the translation files because it should not normally be translated automatically as part of the UI. For dynamic UI messages, I would use translation keys and pass the required values into the translation when needed.
