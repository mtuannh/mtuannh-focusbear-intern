## Which AI tools did you try?

I tried ChatGPT as an AI coding assistant. I used it mainly for coding questions, debugging, generating small code examples, and explaining concepts that I was not familiar with.

## What worked well? What didn't?

ChatGPT was useful for quickly explaining code and suggesting possible solutions when I was unsure how something worked. For example, I could provide a small piece of code and ask it to explain what each part was doing. It was also useful for generating simple code snippets that I could use as a starting point.

However, I found that AI-generated code still needs to be checked before using it. Sometimes the suggested solution may not match the existing code structure or the requirements of the task. Because of this, I think it is better to use AI as a support tool rather than relying on it to solve the whole problem.

## Experimenting with AI for development

### Generating code snippets

I used ChatGPT to generate small code snippets for simple programming problems. This was useful when I wanted to understand different ways of solving a problem or needed a starting point. I found the explanations alongside the code more useful than simply copying the generated code.

### Debugging

I also used ChatGPT to help understand simple coding problems by providing the code and describing the issue. It helped me identify possible causes and suggested changes to try. However, I still needed to test the suggested solution myself to make sure it actually fixed the problem.

### Learning a new concept

I used ChatGPT to explain unfamiliar programming concepts in simpler terms. I found this useful because I could ask follow-up questions when the first explanation was not clear enough.

## When do I think AI is most useful for coding?

I think AI is most useful when I am stuck on a problem, need an explanation of unfamiliar code, or want to explore different ways of solving a problem. It can save time when researching a concept, but I still need to understand and check the solution myself before using it in a project.
