# Navigation

- Ctrl + P: Quickly open any file in the workspace.
- F12: Go to Definition.
- Alt + Left Arrow: Go back to the previous cursor location.

# Editing

- Alt + Click: Add another cursor (Multiple Cursors). 
- Ctrl + D: Select the next occurrence of the current word. 
- F2: Rename a symbol across the project. 
- Shift + Alt + F: Format the entire document.

# Debugging

- F5: Start or continue debugging.
- F9: Toggle a breakpoint.

# Terminal Commands

- Ctrl + `: Open or hide the integrated terminal. 
- Ctrl + Shift + `: Create a new terminal.

# Reflection

## Which shortcuts do you think will be the most useful in your daily work?

The shortcuts I expect to use most frequently are **Multiple Cursors**, **Ctrl + D**, **Go to Definition**, **Rename Symbol**, and **Open/Hide Terminal**. Multiple Cursors and Ctrl + D make it much faster to edit repeated code without manually changing each occurrence. Go to Definition helps me quickly understand unfamiliar code, while Rename Symbol safely updates variable and function names throughout the project. The integrated terminal shortcut also saves time by allowing me to run commands without leaving VS Code.

## How can keyboard shortcuts improve your productivity?

Keyboard shortcuts improve productivity by reducing repetitive mouse movements and allowing developers to perform common tasks much faster. They help maintain focus because there is less interruption when navigating files, editing code, debugging, or using the terminal. Over time, these shortcuts become muscle memory, making development more efficient and reducing the time spent on routine actions.
