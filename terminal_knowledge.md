## Which terminal client did you choose? Why?

I chose the Visual Studio Code integrated terminal with PowerShell. It is already integrated into my development environment, making it easy to run Git commands, Node.js applications, and other development tools without switching between different windows.

## What customizations (if any) did you make?

I did not make any customizations. The default PowerShell configuration is sufficient for my current workflow, and I prefer keeping the setup simple while I become more familiar with command-line tools.

## What was the most useful command you learned today?

The most useful command I learned today was `cd`, which allows me to navigate between directories quickly. I also found `ls` (or `dir` in PowerShell) useful for listing files and folders, making it easier to locate project files from the terminal.
