### How does a Kanban board work, and how does it help manage workflow?

A Kanban board is a visual way of managing tasks and workflow. Tasks are represented as cards and placed in different columns depending on their current status. This makes it easier to see what needs to be done, what is currently being worked on, and what has already been completed.

### What do the different columns on a Kanban board represent?

Each column represents a different stage of the workflow. For example, Not Started contains tasks that have not been started yet, In Progress contains tasks currently being worked on, Ready for Review contains completed tasks waiting to be reviewed, and Approved / Done contains tasks that have been completed and approved.

### How do tasks move through the board, and who is responsible for updating them?

Tasks move from one column to another as their status changes. The person working on the task is usually responsible for keeping its status updated so that the rest of the team can see the current progress.

### What are the benefits of limiting Work in Progress (WIP)?

Limiting WIP helps prevent people from working on too many tasks at the same time. It allows the team to focus on finishing existing work before starting something new. This can reduce context switching and make the workflow more efficient.

## Reflection

### How does Kanban help manage priorities and avoid overload?

Kanban makes priorities more visible because I can see all my tasks and their current status in one place. It also helps avoid overload by showing how much work is currently in progress. Instead of starting several tasks at once, I can focus on completing the most important task before moving to the next one.

### How can you improve your workflow using Kanban principles?

I can improve my workflow by keeping my tasks organised and limiting the number of tasks I work on at the same time. I can also make sure that I update the status of my tasks regularly so I always know what I am currently working on and what I should focus on next.
