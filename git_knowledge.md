## Have you used Git before? If so, in what context?

Yes. I have used Git for multiple university projects and personal programming projects. I also have been using GitHub to collaborate with teammates, manage branches, commit changes, and submit assignments.

## Which Git client (if any) did you choose? Why?

I chose the Git integration in Visual Studio Code because it is convenient and already built into my development environment. It allows me to manage commits, branches, pulls, pushes, and pull requests without leaving the editor.

## What was the most interesting thing you learned about Git today?

The most interesting thing I learned is how Git separates local and remote repositories. I also learned more about the Git workflow, including committing changes locally before pushing them to GitHub, which makes version control safer and more flexible.
