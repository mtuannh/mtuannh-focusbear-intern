# AI Usage Guidelines

## What AI tools are typically used for my role?

For my role as a frontend developer, AI tools can be useful for coding questions, debugging, explaining unfamiliar code, and generating small code snippets. I have mainly used ChatGPT for these purposes.

## What are the benefits and risks of using AI in a professional setting?

AI can help save time when I am stuck on a problem or need to understand something quickly. It can also give me different approaches to solve a coding problem.

However, AI-generated answers are not always correct and may not match the requirements or existing structure of a project. There is also a risk of sharing confidential information with an AI tool if I am not careful. Because of this, I should always check the output before using it.

## What types of information should never be entered into AI tools?

I should not enter confidential company information, private user data, passwords, API keys, access tokens, or other sensitive information into AI tools. I should also avoid sharing private code or information that I am not authorised to share.

If I need help with a problem, I can remove sensitive information and use a smaller or simplified example instead.

## How can you fact-check and validate AI-generated content?

I can check the answer against the project's existing code, documentation, and other reliable sources. For code, I should also test the solution myself instead of assuming that it works just because the AI suggested it.

## When should you use AI for assistance, and when should you rely on your own skills?

I would use AI when I am stuck, need an explanation, or want to explore different ways of solving a problem. I should rely on my own skills when I already understand the problem and can solve it myself, especially when making decisions about the existing project.

AI should help me understand and solve problems rather than replace my own thinking.

## How can you avoid over-reliance on AI while still benefiting from it?

I can try to understand the problem myself before asking AI for help. When I receive an answer, I should read and test it instead of copying it directly. I can also use AI to explain why a solution works so that I learn from it rather than only using the final answer.

## What steps will you take to ensure data privacy when using AI tools?

Before using an AI tool, I will check that I am not including confidential company information, user data, passwords, API keys, or other sensitive information. If I need to show an example of a problem, I can remove or replace private information first.

I will also follow Focus Bear's privacy requirements and ask my supervisor if I am unsure whether certain information can be shared.

## AI experiment

I used ChatGPT to help with a small coding problem and asked it to generate a simple code snippet and explain how it worked. The response gave me a useful starting point and helped me understand the logic behind the solution.

However, I still needed to review the code and make sure it matched what I was trying to do. This showed me that AI can be useful for getting ideas and explanations, but I should not assume that the generated code is automatically correct.

## What worked well and what needed checking?

The explanation was useful because I could ask follow-up questions when I did not understand something. The generated code also gave me a starting point instead of having to work everything out from the beginning.

The main thing that needed checking was whether the suggested solution actually matched the problem and requirements. I would still test the code and make changes when necessary.

## Best practice I will follow at Focus Bear

My main rule will be to **never put confidential or sensitive information into an AI tool and always review AI-generated output before using it**. I will use AI as a support tool for learning and problem-solving while still taking responsibility for the final code and decisions.
